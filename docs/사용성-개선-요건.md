# 사용성 · 디자인 개선 요건

> 아직 구현 전. 앱을 실제로 켜서 화면마다 눌러 본 결과(2026-11)를 바탕으로 정리함.
> 한 줄 요약: **기능을 더하지 않고, 보이는 것을 줄이고, 어디서든 같은 동작이 통하게 한다.**
> 목표: 처음 켠 사람이 "돈 받고 파는 앱 같다"고 느끼는 완성도.

## 0. 쉽게 말하면

지금 앱은 장난감이 가득한 방과 같음. 장난감은 다 좋은데 바닥에 전부 나와 있어서 뭘 먼저 집어야 할지 모름.
그래서 할 일은 네 가지임.

1. **서랍에 넣기**: 자주 쓰는 것만 밖에 두고 나머지는 서랍(버튼 하나) 안으로.
2. **손잡이 맞추기**: 어느 서랍이든 같은 방법으로 열리게.
3. **길 잇기**: 한 장난감에서 다른 장난감으로 바로 건너가게.
4. **방 꾸미기**: 벽지 · 가구 색을 하나로 맞추고 삐뚤어진 곳을 바로잡기.

## 1. 왜 고치나 (지금 불편한 점)

| 본 것 | 왜 불편한가 |
|---|---|
| 위쪽 탭 5개 (전체 · 구상 · 타임라인 · 관계망 · 위키) | 어디서 시작할지 한눈에 안 들어옴 |
| 타임라인 한 줄 보기 위쪽에 조절 장치 10개쯤 | 원고보다 버튼이 먼저 보임 |
| 예시 작품 12화 중 9화가 빈 칸 | 내용 없는 칸이 화면을 차지함 |
| 카드가 가는 곳 5곳 (화 · 보관 · 무덤 · 휴지통 · 위키), "폐기"와 "삭제"가 다름 | 지우려다 멈칫함 |
| 보드에서는 우클릭 메뉴, 타임라인에서는 올리면 나오는 막대 | 같은 카드인데 다루는 법이 다름 |
| 구상은 베이지, 타임라인은 푸른 회색, 위키는 흰색 | 앱 세 개를 붙여 놓은 것처럼 보임 |
| 창을 1100px 아래로 줄이면 검색 · 메뉴 버튼이 창 밖으로 나감 | 누를 수 없음 (버그) |

## 2. 지킬 원칙 5개

모든 요건은 이 다섯 가지에서 나옴. 새 기능을 넣을 때도 이걸로 판단함.

1. **한 화면에 할 일 하나.** 화면마다 주인공(보드 · 원고 · 문서)이 가장 크고, 버튼은 조연.
2. **자주 쓰는 것만 밖에.** 한 막대에 보이는 조절 장치는 5개까지. 나머지는 "보기 설정" 안으로.
3. **같은 것은 어디서나 같게.** 카드 · 인물 이름 · 화 번호는 어느 화면에서든 같은 모양, 같은 메뉴, 같은 반응.
4. **묻지 말고 되돌리게.** 확인 창으로 막지 않고, 바로 하고 "되돌리기"를 줌. 정말 못 되돌리는 것만 물음.
5. **막다른 길 없음.** 어디로 건너가든 보던 자리로 돌아올 수 있음.

## 3. 요건

우선순위: **필수** (없으면 파는 앱처럼 안 보임) · **권장** (있으면 확실히 좋아짐) · **나중** (여유 될 때)

### 3-1. 단순하게 보이기

| 번호 | 요건 | 다 됐는지 보는 법 | 순위 |
|---|---|---|---|
| A1 | 위쪽 탭은 **구상 · 타임라인 · 위키** 3개. "전체"는 구상 왼쪽 목록의 한 줄로, "관계망"은 구상 안의 버튼으로 옮김 | 탭이 3개이고, 전체 보드 · 관계망에 2번 안에 눌러 갈 수 있음 | 필수 |
| A2 | 타임라인 위쪽 막대에는 **보기 바꾸기 · 범위 · + 화**만. 분류 · 글 폭 · 글자 크기 · 원고 모양 · 보관함은 "보기 설정" 버튼 하나 안으로 | 어느 보기에서도 막대의 조절 장치가 5개 이하 | 필수 |
| A3 | 빈 화는 접어서 보임. 글이 있는 화 + "+ 새 화" 한 칸만 | 예시 작품을 열면 화 3개와 새 화 칸만 보임 | 필수 |
| A4 | 무덤과 휴지통을 **"치운 카드"** 한 곳으로. 안에서 "안 쓰기로 한 것 / 지운 것" 두 묶음 | 카드를 없애는 말이 화면 전체에서 "치우기" 하나 | 권장 |
| A5 | 알기 어려운 말 풀기. 예: "3장 · 숨김 4" → "안 쓴 카드 3 · 쓴 카드 4" | 처음 보는 사람이 설명 없이 뜻을 맞힘 | 필수 |
| A6 | 설정은 자주 바꾸는 것만 먼저 보이고, 나머지는 "더 보기"로 접음 | 설정 첫 화면이 스크롤 없이 한 화면에 들어옴 | 권장 |
| A7 | 빈 화면마다 **다음에 할 일 한 가지**를 버튼으로 안내 (빈 보드 · 빈 위키 · 빈 무덤) | 빈 화면에 안내 문장과 버튼이 하나씩 있고, 다른 표시와 겹치지 않음 | 필수 |

### 3-2. 동작을 편하게

| 번호 | 요건 | 다 됐는지 보는 법 | 순위 |
|---|---|---|---|
| B1 | 삭제 · 치우기 · 옮기기는 **확인 창 없이 바로** 하고, 아래 알림에 "되돌리기" 버튼을 5초쯤 띄움 | 카드를 지우고 알림의 되돌리기를 누르면 제자리로 돌아옴 | 필수 |
| B2 | 확인 창은 되돌릴 수 없는 일에만 (치운 카드 비우기 · 예시 지우기 · 작품 지우기) | 확인 창이 뜨는 곳이 목록으로 셀 수 있을 만큼 적음 | 필수 |
| B3 | **카드 메뉴 통일.** 보드 · 타임라인 · 오른쪽 목록 어디서든 우클릭하면 같은 메뉴, 같은 순서 | 세 곳의 메뉴 항목이 같음 (그 자리에서 뜻 없는 항목만 흐리게) | 필수 |
| B4 | ⌘F 검색창이 **명령창**도 겸함. "3화" · "새 인물" · "어두운 테마"처럼 이동과 실행 | 메뉴를 열지 않고 검색창만으로 화면 이동 · 새로 만들기 · 설정 바꾸기가 됨 | 권장 |
| B5 | **뒤로 가기** (⌘[ · 위쪽 ← 버튼). 검색 · 링크로 건너뛴 뒤 보던 자리로 | 인물 → 화 → 위키로 건너간 뒤 두 번 누르면 처음 자리 | 필수 |
| B6 | 끌어다 놓을 때 **놓일 자리가 미리 보임**. 못 놓는 곳은 표시가 안 뜸 | 끄는 동안 어디에 들어갈지 항상 알 수 있음 | 권장 |
| B7 | 마우스 없이도 주요 흐름이 됨. Tab 순서가 화면 순서와 같고, 지금 어디 있는지 테두리로 보임 | 키보드만으로 카드 쓰기 → 화에 넣기 → 원고 내보내기 | 권장 |
| B8 | 단축키는 버튼에 마우스를 올리면 항상 같이 보임 | 단축키가 있는 버튼의 설명에 단축키가 빠진 곳이 없음 | 나중 |

### 3-3. 기능끼리 이어지게

규칙 하나: **이름이 보이는 곳은 어디든 똑같이 반응한다.**

| 번호 | 요건 | 다 됐는지 보는 법 | 순위 |
|---|---|---|---|
| C1 | 인물 · 설정 이름이나 점에 올리면 **작은 카드** (소개 · 목표 · 나온 화)가 뜨고, 누르면 그 보드로 감. 보드 · 타임라인 · 위키 · 관계망 · 검색 결과 모두 같음 | 다섯 곳에서 같은 작은 카드가 뜸 | 필수 |
| C2 | 작은 카드의 "나온 화 1 · 2 · 3"을 누르면 타임라인의 그 화로 감 | 인물에서 그 인물이 나온 화까지 2번 안에 | 필수 |
| C3 | 화 머리에 그 화에 나온 인물이 보이고, 누르면 그 인물 카드만 남음 | 화 머리에서 인물을 눌러 걸러 보고, 다시 눌러 풀 수 있음 | 권장 |
| C4 | 관계망의 선을 누르면 두 사람이 함께 나온 카드가 모임 (지금 동작은 구현 전에 먼저 확인) | 선 하나에서 그 근거가 된 카드를 볼 수 있음 | 권장 |
| C5 | 화 번호가 보이는 곳 (위키 본문 · 검색 · 등장표)은 눌러서 그 화로 감 | 화 번호가 글자로만 있는 곳이 없음 | 권장 |
| C6 | 작품 노트의 "연재 진행"은 **글이 있는 화**만 셈 | 빈 화를 더해도 숫자가 안 늘어남 | 필수 |
| C7 | 검색이 작품 노트(컨셉 · 아이디어)와 치운 카드까지 찾음 | 앱 안에 쓴 글 중 검색에 안 잡히는 곳이 없음 | 권장 |

### 3-4. 깔끔하고 예쁘게

| 번호 | 요건 | 다 됐는지 보는 법 | 순위 |
|---|---|---|---|
| D1 | **바탕색 하나.** 세 탭의 바탕 · 옆 패널 · 위쪽 막대가 같은 색 묶음을 씀 (코르크 무늬는 보드 안쪽만) | 탭을 바꿔도 바탕색이 안 바뀜 | 필수 |
| D2 | **강조색 하나.** 파란색은 "지금 누를 것" 한 군데에만. 화면마다 파란 버튼은 1개 | 한 화면에 채운 파란 버튼이 2개 이상 없음 | 필수 |
| D3 | **글자 크기 3단계** (제목 · 본문 · 보조). 보조 글자도 12px 아래로 안 내려감 | 화면에서 쓰는 글자 크기가 3가지 (원고 글자 크기 조절은 예외) | 필수 |

| D5 | **버튼 모양 3가지** (채운 것 · 테두리 · 글자만). 아이콘과 글자는 떨어뜨려 나란히 | "⤓원고" · "+화"처럼 붙은 버튼이 없음 | 필수 |
| D6 | 아이콘은 같은 굵기 · 같은 크기 한 벌 | 옆에 놓인 아이콘끼리 굵기가 다르지 않음 | 권장 |
| D7 | **움직임 규칙 하나.** 열고 닫는 건 0.15 ~ 0.25초, 같은 곡선. 움직임 줄이기 설정을 따름 | 패널 · 메뉴 · 창이 같은 느낌으로 열림 | 권장 |
| D8 | 어두운 테마도 같은 수준. 포스트잇 · 말풍선 · 그림자가 어두운 바탕에 맞게 따로 조정됨 | 어두운 테마에서 눈에 튀는 흰 조각이 없음 | 권장 |
| D9 | 모서리 둥글기 · 그림자는 2단계까지 (카드 / 떠 있는 창) | 둥글기 값이 2가지 | 나중 |

### 3-5. 파는 앱다운 마감

눈에 덜 띄지만, 빠지면 바로 "만들다 만 앱"처럼 보이는 것들.

| 번호 | 요건 | 다 됐는지 보는 법 | 순위 |
|---|---|---|---|
| E1 | **900px 창에서도 안 잘림.** 좁아지면 옆 패널이 먼저 접히고, 버튼이 창 밖으로 안 나감 | 900 × 600 창에서 모든 버튼을 누를 수 있고 가로 넘침이 없음 | 필수 |
| E2 | 겹치고 잘리는 곳 없음: 칸반 첫 카드의 도구 막대, 화 머리 버튼과 글자 수, 좁은 보드의 아래 도구 막대, 관계망 이름표 | 900 · 1200 · 1440px 창과 밝은 · 어두운 테마에서 겹침 0곳 | 필수 |
| E3 | **첫 3분 안내.** 처음 켜면 "적기 → 화에 넣기 → 원고로 보기" 세 걸음만 직접 해 보게 함 | 처음 쓰는 사람이 3분 안에 원고 한 화를 만들어 봄 | 권장 |
| E4 | 실패는 사람 말로, 다음 할 일과 함께. 예: "저장하지 못했어요 · 다시 시도 · 백업 받기" | 오류 알림마다 누를 버튼이 하나 이상 | 필수 |
| E5 | 화면 읽기 프로그램용 이름. 아이콘만 있는 버튼 전부에 `aria-label` | 이름 없는 버튼 0개 | 권장 |
| E6 | 카드 500장 · 화 100개 작품에서도 탭 바꾸기 · 글자 입력이 버벅이지 않음 | 큰 예시 작품에서 탭 바꾸기 0.2초 안 | 권장 |
| E7 | 안내 문서가 화면과 같음. README의 없어진 설정 설명 (화면 디자인 → 새단장) 정리 | README를 따라 눌렀을 때 없는 메뉴가 없음 | 필수 |
| E8 | 서명된 설치 파일. 처음 열 때 "알 수 없는 앱" 경고가 안 뜸 (인증서 비용이 드는 일이라 따로 결정) | Windows · 맥에서 경고 없이 열림 | 나중 |

## 4. 안 하는 것

- 새 기능 추가 (찾아 바꾸기 · 화 상태 · 분량 목표 · .docx 내보내기 등)는 이 요건에 넣지 않음. 정리가 끝난 뒤 따로 다룸.
- 데이터 모양은 바꾸지 않음. A4(치운 카드)도 화면에서만 합치고, 저장된 무덤 · 휴지통 구조는 그대로 둠.
- 지금 되는 기능은 없애지 않음. 자리만 옮김.

## 5. 순서

| 단계 | 하는 일 | 요건 |
|---|---|---|
| 1 | **고장 난 곳부터**: 잘림 · 겹침 · 틀린 숫자 · 옛 문서 | E1 · E2 · C6 · E7 |
| 2 | **보이는 것 줄이기**: 탭 · 막대 · 빈 화 · 말 · 빈 화면 | A1 · A2 · A3 · A5 · A7 |
| 3 | **동작 맞추기**: 되돌리기 · 메뉴 통일 · 뒤로 가기 | B1 · B2 · B3 · B5 |
| 4 | **잇기**: 이름 카드 · 나온 화 | C1 · C2 |
| 5 | **꾸미기**: 색 · 글자 · 버튼 | D1 · D2 · D3 · D5 · E4 |
| 6 | 권장 · 나중 항목 | 나머지 |

- 2단계의 A1(탭 3개)과 A4(치운 카드)는 쓰던 습관이 바뀌는 결정이라, `design/` 폴더에 **시안을 먼저 만들어 보고** 정함.
- 5단계는 화면 전체 모양이 바뀌므로, 고치기 전후를 `e2e/style-snapshot.js`가 아니라 스크린샷으로 비교함 (모양이 바뀌는 게 목적이라서).

## 6. 다 됐는지 보는 큰 기준

1. 처음 켠 사람이 설명 없이 3분 안에 카드를 쓰고, 화에 넣고, 원고로 봄.
2. 어느 화면에서든 조절 장치가 한 막대에 5개 이하.
3. 900 · 1200 · 1440px 창, 밝은 · 어두운 테마에서 잘리거나 겹친 곳 0.
4. 세 탭을 번갈아 봐도 한 앱으로 보임 (바탕색 · 글자 · 버튼이 같음).
5. 어디로 건너가든 "뒤로"로 돌아오고, 무엇을 지우든 "되돌리기"로 살림.
