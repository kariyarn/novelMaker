# 위키 탭 요건

> 1단계 구현 완료: `storyline-app/src/features/wiki.js` · `styles/wiki.css` · 테스트 `test/wiki.test.js`

> 레드마인 노트의 '업무 위키'를 소설 쓰기에 맞게 옮긴 것.
> 한 줄 요약: **장면은 화에 넣고, 메모는 위키에 넣는다.** 구상은 어디서든 자유롭게, 설정 정리는 위키 탭에서.

## 1. 왜 만드나

- 타임라인은 장면 · 대사로만 정리하고, 메모는 타임라인에 잘 넣지 않음.
- 그런데 지금 무덤 규칙은 "7일 안에 화나 보관 칸에 넣지 않으면 무덤"이라, 별을 붙이지 않은 메모는 대부분 무덤으로 감.
- 설정 노트의 '설정 메모'는 텍스트 칸 하나뿐이라 세계관 · 규칙처럼 길고 구조가 있는 글을 정리할 곳이 없음.

## 2. 분류마다 '가는 곳'

설정 → 글쓰기 → 분류 목록에 **가는 곳: 원고 / 위키** 를 추가함. 분류를 몇 개로 늘려도 규칙은 이 두 가지뿐임.

| | 원고 분류 (기본: 장면 · 대사) | 위키 분류 (기본: 메모) |
|---|---|---|
| 구상 보드 | 보임 | 보임 |
| 오른쪽 목록 | 보임 | 보임 (위키에 넣기 전까지) |
| 타임라인 · 원고 내보내기 | 넣을 수 있음 | 넣을 수 없음 |
| 위키 | 넣을 수 없음 | 넣을 수 있음 |
| 무덤 | 화 · 보관 칸에 넣으면 안 감 | 위키에 넣으면 안 감 |

- 새 분류를 만들 때 가는 곳을 고름 (기본값: 원고).
- 이미 화에 들어가 있는 위키 분류 카드는 그대로 둠 (빼면 다시 넣을 수 없음).
- 분류의 가는 곳을 바꿔도 이미 들어간 카드는 그대로 둠.

## 3. 위키의 생김새

### 3-1. 나무

```
폴더 (지금 왼쪽 목록의 폴더 그대로)
└ 인물 · 설정 노트
  └ 행 (= 문서 하나, 제목 + 본문)
    └ 하위 행 …
작품 전체 (어느 인물 · 설정에도 안 묶인 행)
└ 행 …
```

- 맨 위 두 층(폴더, 인물 · 설정 노트)은 왼쪽 목록과 같은 데이터를 씀. 위키에서 따로 만들거나 이름을 바꾸지 않음.
- 그 아래 행만 위키의 데이터임. 행 안에 행을 몇 단이든 넣을 수 있음.
- 인물 노트, 설정 노트 모두 위키에 나옴.

### 3-2. 화면 (새 탭)

- 위쪽 탭: `전체 · 구상 · 타임라인 · 관계망` 옆에 **위키** 추가.
- 업무 위키처럼 **열 보기**: `폴더 · 인물 · 설정 │ 행 │ 하위 행 │ … │ 편집기`.
- 오른쪽 목록은 위키 탭에서도 열려 있음. 기본으로 위키 분류 카드만 보이고, 여기서 메모를 끌어 나무에 놓음.

## 4. 메모 → 행

메모 카드를 위키 나무의 원하는 자리(인물 · 설정 아래, 또는 다른 행 아래)에 끌어 놓으면:

1. 새 행이 생김. **메모 글이 그 행의 제목**이 됨.
   - 메모가 한 줄이면 제목 = 그 줄, 본문은 비어 있음.
   - 여러 줄이면 첫 줄 = 제목, 나머지 줄 = 본문.
   - 제목은 나중에 따로 고칠 수 있음 (고쳐도 원래 카드 글은 그대로).
2. 원래 카드는 **정리됨** 상태가 되어 오른쪽 목록에서 숨고 무덤 타이머가 멈춤. 지우지는 않음.
3. 행에서 **원본 카드 보기 · 되돌리기**를 할 수 있음. 되돌리면 행은 휴지통으로 가고 카드는 오른쪽 목록으로 돌아옴 (무덤 타이머는 처음부터).

메모 없이 위키에서 바로 새 행을 만들 수도 있음.

## 5. 본문

- 서식: 제목(2단계) · 굵게 · 기울임 · 목록 · 인용 · 형광펜. 단축키는 업무 위키와 같게.
- `[[` 를 치면 인물 · 설정 · 다른 행 · 화를 골라 연결함.
  - 이름이 아니라 id로 저장함. 원래 항목의 이름을 바꿔도 링크가 깨지지 않음.
  - 누르면 그 항목으로 이동함.
- 행 아래에 자동으로 보여 줌:
  - **이 행을 가리키는 행** (역링크)
  - **인물 · 설정 노트의 행이면: 그 인물 · 설정이 나온 화**

## 6. 기존 데이터 옮기기

- 설정 노트의 '설정 메모'에 글이 있으면, 그 설정 아래 **'설정 메모'** 행 하나로 옮김. 설정 시트의 메모 칸은 없애고 "위키에서 보기" 링크로 바꿈.
- 메모 카드는 그대로 둠. 사용자가 직접 끌어 넣을 때만 행이 됨.

## 7. 함께 바뀌는 곳

- **전체 검색(⌘F)**: 행 제목 · 본문도 찾음.
- **휴지통 · 되돌리기**: 행 삭제도 휴지통으로 감. 하위 행이 있는 행은 하위 행과 함께 감.
- **동기화(합치기)**: 행 단위로 합침. 같은 행을 양쪽에서 고친 경우만 어느 쪽을 쓸지 고름 (카드와 같은 방식).
- **본문 저장**: 동기화로 다른 기기에서 들어오는 HTML도 있으니, 업무 위키처럼 허용 목록(태그 · 속성)만 남기고 저장함.
- **내보내기**: 위키 전체 또는 한 인물 · 설정 아래를 Markdown 으로.

## 8. 1단계에서 뺄 것

표 · 사진 · 글자색 · 글자 크기 · 암호 잠금 · .html 내보내기. 써 보고 필요하면 넣음.

## 9. 데이터 모양 (안)

```js
S.wiki = [{
  id, owner,        // 묶인 인물 · 설정 id, 작품 전체면 'work'
  parent,           // 상위 행 id, 인물 · 설정 바로 아래면 null
  pos,              // 같은 층 안 순서
  title, body,      // body: 허용 목록으로 거른 HTML
  from,             // 메모에서 만들었으면 원래 카드 id
  created, updated
}]
// 카드: c.filed = 행 id  (정리됨 표시. 있으면 오른쪽 목록 · 무덤에서 빠짐)
// 분류: k.dest = 'draft' | 'wiki'
```

## 10. 정한 것

- 정리된 메모는 **구상 보드에 흐리게 남고** '📖 위키에서 보기'가 붙음. 누르면 그 행으로.
- 메모 하나가 여러 인물 · 설정에 연결돼 있어도 **놓은 자리 한 곳**에만 행이 생김. '위키로 ▸'는 연결된 곳을 후보로 먼저 보여 줌.
- 탭 이름은 **위키**.
- 좁은 창: 앞쪽 열을 띠로 접지 않고 **파인더처럼 왼쪽으로 밀려 나감** (가로 스크롤 · 왼쪽 가장자리 흐림).

## 11. 1단계에 함께 넣은 것

1. **끌지 않고 넣기**: 메모의 '위키로 ▸' → 연결된 인물 · 설정 / 지금 연 행 / 작품 전체 / 다른 곳 고르기. 구상 보드 · 오른쪽 목록 우클릭에도 '위키에 넣기…'.
2. **엿보기**: 타임라인 · 오른쪽 목록의 인물 점 · 이름표(data-ent)에 마우스를 올리면 그 인물 · 설정의 행 목록, 누르면 본문 미리보기.
3. **곧 무덤 갈 메모 먼저**: 정리할 메모는 D-1 → D-3 → 별 → 최신 순.
4. **여러 장 한꺼번에**: ⌘ 클릭으로 고른 메모를 행 하나로 (첫 장 첫 줄 = 제목, 나머지 장 = 본문 목록).
5. **초록 숫자**: 첫 열의 정리 안 한 메모 수를 누르면 오른쪽 목록이 그 메모만.
6. **파인더 키보드**: ↑↓ ← → · Enter 이름 바꾸기 · ⌘N 새 행 · ⌘⌫ 휴지통 · 글자를 쳐서 찾기.
7. **행 옮기기**: 끌어서 위 · 아래 가장자리 = 사이, 가운데 = 하위 행, 첫 열 = 다른 인물 · 설정 아래.
8. 본문 마크다운 입력(`- ` `1. ` `# ` `## ` `> `) · ⌘B · ⌘I · ⌘⇧H(형광펜) · ⌘⌥1/2/0.
9. 인물 시트 · 설정 노트 · 설정 표에 위키 칸, 전체 검색(⌘F)에 위키 행, 설정 → 데이터 → 내보내기 '위키 .md', 도움말 '위키' 탭.
